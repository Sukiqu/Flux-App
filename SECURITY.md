# Security policy

Flux is maintained by **sukiqu**. Please report suspected security issues through
GitHub's private vulnerability reporting when it is available for this repository.
Do not include exploit details, private files or personal logs in public issues.

If private reporting is unavailable, open a short public issue asking for a private
contact method without describing the vulnerability.

Use release files from the official repository and keep downloaded archives intact
until you have finished any checks you want to perform. Security notices and fixes
are documented in the relevant release notes.
