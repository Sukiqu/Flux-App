# Changelog

Concise, user-facing summaries of the major Flux releases.

## 2.1.0 — 2026-10-02

- Updated Flux branding across the application, executable and Windows icon.
- Refined compatibility, packaging and documentation for the 2.1.0 release.
- Preserved panel themes, localized settings and shared hover highlights.
- Completed missing interface translations and aligned help text with current options.
- Added the Vinyl theme with a rotating record and refined metallic appearance.
- Improved theme previews, playback controls and automatic performance optimization.

## 2.0.0

- Added the redesigned settings dashboard, theme system and application accent colors.
- Added in-app version and help pages with smoother navigation and refreshed rendering.
- Expanded independent panel customization for appearance, placement and timing.

## 1.19

- Added independent settings for media, volume and lock panels.
- Updated the settings experience with panel-specific appearance and behavior controls.

## 1.11.2

- Updated documentation, localization and panel previews.
- Corrected Caps Lock, Num Lock and Scroll Lock icon behavior while preserving saved settings.

## 1.5.2

- Improved panel transparency, text alignment and resource handling.
- Updated rapid play/pause processing and playback state presentation.

## 1.5.1

- Reworked panel edge rendering to remove hard, pixelated corners.
- Improved rounded edges with smoother alpha rendering and high-resolution scaling.

## 1.0.1

- Added the first customizable Windows flyouts for media, volume and keyboard lock notifications.
- Added localized settings and independent panel behavior.
